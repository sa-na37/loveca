Last updated: 2026-02-25

0. 運用ルール（固定）
- 仕様の最終判断は spec.txt を正とする（矛盾は確認→specへ反映）。
- llocg_handoff.txt は時系列ログ（参照用）。現状（Single Source of Truth）は snapshot/CURRENT_STATUS で別管理する。
- 更新配布は「zip上書き」が基本。ユーザーは “ダウンロード→コマンド貼り付け” のみで運用（手編集しない）。

1. Repo/パス
- Repo: git@github.com:sa-na37/loveca.git (branch main)
- 作業ルート: ~/Desktop/gsim/loveca
- DB/画像: ./llocg_db_out_full（card_images含む）
- decklists: ./llocg_db_out_full/decklists/<code>.tsv（例: 1RCBL）
- 起動: python3 run_llocg_ui_web.py（deck-code=1RCBL が既定）

2. 開発方針（確定）
- エンジン（llocg_ui/engine.py）は “jank互換” を凍結し、UI（llocg_ui/server.py）のみを修正。
- clean系UIへ段階移行（右側パネルは UNDO/NEXT 主体、不要ボタン排除）。
- ファイルは同名上書き運用（別名バージョン増殖を避ける）。
- コマンド例は /path/to などのプレースホルダを使わず、~/Downloads 前提で「展開→起動」まで1セットで提示。

3. これまでに解決した主な不具合（経緯）
- Git push 認証: HTTPSパスワード不可 → SSH鍵登録で push/pull 安定化。
- JSクラッシュ系:
  - Illegal return statement → inline JS を IIFE で包んで解消
  - pending null crash → state.pending のガードで解消
  - Invalid/unexpected token → JS文字列の改行混入を除去
- HTTP: curl -I が 501 → do_HEAD + body抑止で解消（GET/HEADが200に）
- UI/操作系:
  - 右側ボタンの仕様逸脱（yell/attempt/ack等）を排除し UNDO/NEXT中心へ
  - 解決領域ポップアップがNEXTを塞ぐ → 右パネル非遮蔽 + サイズ調整
  - エネルギー表示が見えない → 背景付き表示へ
  - LIVE成功/失敗通知 → 前面化 + 自動消去
  - LIVE SETは3枠固定（枚数変動でも位置が動かない）
  - 解決領域のLIVE横向き → portrait表示へ統一
  - “カード画像がクリックを吸って処理できない” → ステージカードも枠クリック扱いにして回避
- 効果処理:
  - 途中終了（Skip）が必要な pending で Skip ボタンを提供（10コスト栞子など）

4. 現状のUI（安定）
- 解決領域（resolve）: 自動でカードリスト表示、NEXTで進行
- 控え室（waiting room）: クリックでカードリスト表示（Closeあり）
- pending選択: 画像リストで選択（カード番号だけでなく視認可能）
- 手札: 選択枠表示（重なりでも視認できる）

5. 仕様追記（2026-02-25）
- カード一覧（控え室・解決領域・選択ポップアップ等）の並び順:
  「カードタイプ順 > カードナンバー順 > レアリティ順」
- 将来的には結合アプリ化後、設定でソート規則を変更可能にするのが望ましい。
