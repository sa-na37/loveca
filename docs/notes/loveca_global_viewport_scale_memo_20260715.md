# Loveca全画面・基準解像度スケーリング

## 基準

- 基準表示領域：1920×1200
- 最小保証領域：1440×900
- 通常倍率：横幅倍率と縦幅倍率の小さい方
- 最小倍率：55%
- 最大倍率：115%

## 共通適用画面

共通 `page()` を使用する全画面へ適用。

- メニュー
- 手動シミュレータ起動
- リモート対戦
- デッキ管理
- デッキ内容
- デッキ編集
- デッキコード読込
- データ更新
- ログ管理
- 設定
- 診断

## 縦長ページ

1画面へ無理に圧縮しない。
基準倍率を維持し、ページ内容が表示領域より長い場合は通常の縦スクロールを使う。

## デッキ編集

右側の現在デッキ欄は、縮小前の論理表示高さを参照し、
画面下端まで利用するようmax-heightを再計算する。

## 詳細分析

- ヒストグラム高さを50pxから72pxへ拡大
- 上部分析を小さくしすぎない
- カード画像一覧を基準1920幅で12列へ調整
- カード画像上限を116pxへ拡大
- 分析画面は必要に応じて縦スクロール
