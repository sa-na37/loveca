# Loveca Simulator 2026-09-03 Release Notes

## 配布物

- `loveca-windows-20260903.zip`: Windows向け本体
- `loveca-macos-20260903.zip`: macOS向け本体
- `loveca-patch-20260903.zip`: 既存フォルダへ上書きする更新差分
- `loveca-source-20260903.zip`: 管理/開発向け控え

## 既存フォルダからの更新手順

既に `loveca` フォルダがある場合は、まず `loveca-patch-20260903.zip` を使うのがおすすめです。

1. 起動中のLovecaアプリを終了します。
2. `loveca-patch-20260903.zip` を展開します。
3. 展開して出てきた `loveca` フォルダの中身を、今使っている `loveca` フォルダへ上書きします。
4. いつものランチャーから起動します。

初めて使う場合や、更新後に起動できない場合は、OS別の本体zipを新しく展開して使ってください。

## 主な更新

- CPUオート2デッキ対戦の入口を追加・改善し、自分のデッキとCPUのデッキを選んで対戦できるようにしました。
- CPU対戦起動時に、先攻を `ランダム` / `自分が先攻` / `CPUが先攻` から選べるようにしました。
- 手動2デッキ対戦側でも、起動時に先攻指定を選べるようにしました。
- 2デッキ対戦の同値ライブ勝敗、成功ライブ3枚到達、No Game記録などの処理を調整しました。
- UIなしオートプレイ、CPU対戦用オートプレイ、オートプレイ方針レポートの整備を進めました。
- オートプレイモデルで、2エネルギー相当以上の加速・軽減・踏み倒し効果を進行エンジンとして強めに評価するようにしました。
- `Retrofuture`、9コスト花帆、`Music S.T.A.R.T!!`、PR17真姫、15ことり系のような大型進行補助を検出しやすくしました。
- 15ことり型の「ライブ成功時に低コストメンバーを登場させる」効果を、T3の `15-2` 代替進行として扱うようにしました。
- PR17真姫などを絡めた `17-4` 進行も、T3の代替候補として評価するようにしました。
- デッキコード読み込み、プレビューカード取得、PR/再録画像探索、画像不足時の再取得判定を改善しました。
- デッキ構築のラブカポイント、レギュレーション指定、デッキコピー、カード詳細表示、画像表示まわりを調整しました。
- シミュレータのポップアップ、下部カード確認、リセットボタン、スタッツ表示、デバッグモードなどのUIを調整しました。

## 注意

- 本体zipには、外部サイトから取得したカード画像と別配布のUI画像バンドルは含めていません。
- UI画像は、これまで通り別配布の `loveca-ui-assets.zip` または日付付きUIアセットzipを `loveca` フォルダ直下へ置いてください。
- カード画像は、アプリ起動後のデータ更新で取得します。
- オートプレイは現在も精度改善中です。今回の版では大型加速・踏み倒しの評価を強化しましたが、T4/T5以降の複雑な復帰進行、成功置き場参照、対戦相手の公開情報を使った判断は引き続き改善対象です。
