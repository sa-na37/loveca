# Loveca Simulator 2026-07-30 Release Notes

## 配布物

- `loveca-windows-20260730.zip`: Windows向け本体
- `loveca-macos-20260730.zip`: macOS向け本体
- `loveca-patch-20260730.zip`: 既存フォルダへ上書きする更新差分
- `loveca-source-20260730.zip`: 管理/開発向け控え

## 主な更新

- 完全手動2デッキ対戦、CPUオート2デッキ対戦、UIなしオートプレイの入口を分離。
- CPUオート2デッキ対戦に、片側CPU/両側CPU/自動進行切替とCPU判断ログを追加。
- UIなしオートプレイCLIにCSV/JSONサマリ出力を追加。
- CPUのMAIN配置を、目標より大きいカード、目標ぴったり、可能な限り大きい妥協の順に補正。
- CPUのLIVE_SET判断ログに、ターンのライブスコア目標と実際に選んだライブカード番号/スコアを表示。
- CPUのMAIN終了判断を、目標達成済みの `main_complete` と、未達だが改善候補なしの `main_pass` に分離。
- DeckLogデッキコード読込を、Playwright未導入Windows環境でも動くPOST API優先経路へ改善。
- プレビューカード取得で、公式ポスト集約ページの鮮度確認、DB未反映カードの検出、プレビュー画像欠落時の再取得/エラー終了を追加。
- 再録/PR画像探索、カード詳細ポップアップ、デッキ編集固定ヘッダ、横スクロール操作、リセット/勝敗記録など、前回以降のローカル修正を同梱。

## 既存フォルダからの更新手順

既に `loveca` フォルダがある場合は、まず `loveca-patch-20260730.zip` を使うのがおすすめです。

1. 起動中のLovecaアプリを終了します。
2. `loveca-patch-20260730.zip` を展開します。
3. 展開して出てきた `loveca` フォルダの中身を、今使っている `loveca` フォルダへ上書きします。
4. いつものランチャーから起動します。

うまく動かない場合や初めて使う場合は、OS別の本体zipを新しく展開して起動してください。

## 注意

- 本体zipにはカード画像とUI画像バンドルは含めていません。
- UI画像は、これまで通り別配布の `loveca-ui-assets.zip` または日付付きUIアセットzipを `loveca` フォルダ直下へ置いてください。
- プレビューカード画像は、更新時に外部サイトから取得します。今回から、取得漏れが残った場合は更新完了扱いにせずエラーで知らせます。
