## 結論

現行のデバッグメモ上で、明確に「新規実装が未着手」として残っている active debug command はない。

ただし、直近修正後の再確認待ちとして active に残すべき項目が2件ある。これらは実装済みコメント付きだが、ユーザー確認後に追加修正が必要になる可能性がある。
