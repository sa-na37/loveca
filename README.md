# Loveca Simulator 取扱説明書

Loveca Simulator は、ラブライブ！シリーズ オフィシャルカードゲーム（ラブカ / LLCG）をローカル環境で確認するための補助ツールです。

## 初回起動までのガイド

Loveca Simulator は Python という実行環境を使って動きます。

このガイドは、配布者から次の2つを受け取っている想定で書いています。

- GitHub Release のURL
- UI画像バンドル `loveca-ui-assets.zip` または `loveca-ui-assets-日付.zip`

Python を普段使っていない場合でも、次の手順どおりに進めれば起動できます。Windows ユーザーが多い想定のため、Windows の手順を先に記載します。

### ダウンロードするファイル

配布者から受け取った GitHub Release のURLをブラウザで開くと、配布ページが表示されます。

ページ内の `Assets` から、自分のOSに合う本体zipを1つだけダウンロードしてください。

| ファイル名 | 用途 |
| --- | --- |
| `loveca-windows-YYYYMMDD.zip` | Windowsで遊ぶ人向け |
| `loveca-macos-YYYYMMDD.zip` | macOSで遊ぶ人向け |
| `loveca-source-YYYYMMDD.zip` | 管理者/開発者向けの控え |

通常の利用者は、Windowsなら `loveca-windows-YYYYMMDD.zip`、macOSなら `loveca-macos-YYYYMMDD.zip` を選びます。

`loveca-source-YYYYMMDD.zip` は管理者/開発者向けです。普通に遊ぶだけなら不要です。

UI画像バンドル `loveca-ui-assets.zip` は GitHub Release ではなく、配布者から別で受け取ります。日付付きの `loveca-ui-assets-20260721.zip` のような名前でも使えます。本体zipと同じ場所、または後で分かりやすい場所に置いてください。

### Windowsで初めて起動する

1. Python 3 をインストールします。

   ブラウザで次のページを開きます。

   ```text
   https://www.python.org/downloads/
   ```

   `Download Python 3.x.x` のボタンを押して、インストーラーをダウンロードします。

2. インストーラーを起動します。

   最初の画面で、必ず `Add python.exe to PATH` にチェックを入れてください。

   その後、`Install Now` を押します。

   チェックを入れ忘れると、あとで `python` が見つからず起動できないことがあります。その場合は、もう一度インストーラーを起動して `Modify` から PATH 設定を追加するか、Python を入れ直してください。

3. GitHub Release から Windows用の本体zipをダウンロードします。

   配布者から受け取った GitHub Release のURLをブラウザで開きます。

   ページ内の `Assets` を開き、`loveca-windows-YYYYMMDD.zip` をクリックしてダウンロードします。

   ブラウザが保存先を聞いてきた場合は、`ダウンロード` フォルダかデスクトップなど、後で見つけやすい場所を選んでください。

4. Loveca Simulator のフォルダを展開します。

   ダウンロードした `loveca-windows-YYYYMMDD.zip` を右クリックして、`すべて展開` を選びます。

   展開後、`loveca` フォルダの中に次のようなファイルがあることを確認します。

   ```text
   launch_loveca.bat
   run_loveca_app.py
   loveca_app
   llocg_ui
   llocg_db_out_full
   ```

5. UI画像バンドルを配置します。

   配布者から受け取った `loveca-ui-assets.zip` または日付付きのUI画像バンドルを、展開後の `loveca` フォルダ直下に置いてください。

   UI画像バンドルのzip自体は展開しなくて大丈夫です。

   ```text
   loveca
   ├─ launch_loveca.bat
   ├─ run_loveca_app.py
   └─ loveca-ui-assets-20260721.zip
   ```

   初回起動時に、プレイマット、裏面画像、NoImage画像、ハート/ブレードなどのUI用アイコンが自動で配置されます。

6. `launch_loveca.bat` をダブルクリックします。

   黒い画面が一瞬または継続して表示され、その後 `Loveca Application` が開きます。

   初回起動時は、カードデータ更新の確認画面が開く場合があります。更新では外部サイトからカード情報と画像情報を取得します。内容を確認し、更新してよければ `更新する` を押してください。あとで行う場合は `あとで` を押します。

   初回のデータ更新では、更新処理に必要なPython追加部品を自動で確認し、不足している場合は導入してから更新を続行します。

7. 起動しない場合は、コマンドで確認します。

   `loveca` フォルダの何もない場所を右クリックし、`ターミナルで開く` または `PowerShellで開く` を選びます。

   次を入力して Enter を押します。

   ```bat
   python --version
   ```

   `Python 3.10.x` のように表示されれば、Python は認識されています。

   次を入力すると、手動で起動できます。

   ```bat
   python .\run_loveca_app.py
   ```

   それでも起動できない場合は、表示されたエラーメッセージを確認してください。

### macOSで初めて起動する

1. Python 3 が入っているか確認します。

   `ターミナル` を開き、次を入力します。

   ```bash
   python3 --version
   ```

   `Python 3.10.x` のように表示されれば準備済みです。

   表示されない場合は、Python 公式サイトまたは Homebrew から Python 3 をインストールしてください。

   Python 公式サイト:

   ```text
   https://www.python.org/downloads/
   ```

2. GitHub Release から macOS用の本体zipをダウンロードします。

   配布者から受け取った GitHub Release のURLをブラウザで開きます。

   ページ内の `Assets` を開き、`loveca-macos-YYYYMMDD.zip` をクリックしてダウンロードします。

3. Loveca Simulator のフォルダを展開します。

   ダウンロードした `loveca-macos-YYYYMMDD.zip` をダブルクリックして展開し、`loveca` フォルダの中に次のようなファイルがあることを確認します。

   ```text
   launch_loveca.command
   run_loveca_app.py
   loveca_app
   llocg_ui
   llocg_db_out_full
   ```

4. UI画像バンドルを配置します。

   配布者から受け取った `loveca-ui-assets.zip` または日付付きのUI画像バンドルを、展開後の `loveca` フォルダ直下に置いてください。

   UI画像バンドルのzip自体は展開しなくて大丈夫です。

   初回起動時に、プレイマット、裏面画像、NoImage画像、ハート/ブレードなどのUI用アイコンが自動で配置されます。

5. `launch_loveca.command` をダブルクリックします。

   セキュリティ設定で開けない場合は、右クリックして `開く` を選びます。

6. それでも起動しない場合は、ターミナルで `loveca` フォルダへ移動して次を実行します。

   ```bash
   python3 ./run_loveca_app.py
   ```

### 通常の起動方法

macOS:

```bash
./launch_loveca.command
```

Windows:

```bat
launch_loveca.bat
```

うまく起動しない場合は、Python 3.10 以上が入っているか確認してください。

## メニュー

起動すると `Loveca Application` が開きます。

- `デッキ`: 使用デッキの選択、デッキ内容の確認、デッキ編集
- `シミュレータ`: 1デッキ用の一人回し
- `リモート対戦`: 2デッキを使う対戦確認
- `更新`: カードデータ、商品情報、カード画像の更新
- `ログ`: 保存されたログの確認
- `設定`: プレイヤー識別子、リモート対戦キー、起動時更新確認の設定
- `診断`: アプリ、Python、DB、画像数などの確認

## 基本操作

1. アプリを起動します。
2. `デッキ` を開き、使用するデッキを選びます。
3. デッキ一覧の開始ボタン、またはメニューのシミュレータ入口から対戦を開始します。
4. マリガン画面では、戻したいカードを選んで `マリガン決定` を押します。
5. 画面上のボタンやカードを操作して、フェイズ進行、プレイ、ライブ処理を行います。

## カードデータ更新

設定画面の `起動時にカードデータ更新を確認する` が有効な場合、アプリ起動後に更新確認画面を表示します。

更新では外部サイトからカード情報と画像情報を取得します。確認画面で許可した場合のみ、更新を開始します。

初回の更新では、`requests` などのPython追加部品を自動で確認し、不足している場合は導入してから更新を続行します。

手動で更新する場合は、メニューの `更新` を開いて `更新開始` を押してください。

更新では次の内容を確認します。

- カードテキスト
- 商品情報
- 先行公開カード情報
- カード画像
- DB生成結果の整合性

更新に失敗した場合でも、既存のカードデータでアプリは起動したままになります。エラー内容は `更新` ページのログで確認できます。

外部サイトへのアクセス回数を減らすため、商品ページは長期キャッシュを優先して再利用します。新しい商品ページなど、まだ保存されていないページだけ取得が必要になります。

配布zipには、初回更新時のアクセス集中を避けるため、事前取得済みの商品ページ/更新用HTMLキャッシュを一部同梱しています。キャッシュにない新規ページだけ外部サイトから取得します。

起動時の更新確認を一時的に止めたい場合:

```bash
python3 ./run_loveca_app.py --skip-startup-update
```

## 中断と再開

シミュレータでは、途中状態を保存して再開できます。

- 保存した中断データから同じ状態を再開できます。
- 分岐確認をしたい場合は、同じ中断データを複数回読み込んで試せます。

## カード画像

GitHubで配布する本体zipには、外部サイトから取得したカード画像は含めません。

カード画像は、アプリ起動後に更新画面から取得してください。取得はユーザーが許可した場合のみ行います。

カード画像が見つからない場合は、UI画像バンドルに含まれるNoImage画像が表示されます。UI画像バンドルがない場合は、画像なし表示になります。

エネルギー下敷き用の仮カードは、専用画像 `energy.png` があればそれを使います。見つからない場合は無地表示になります。

## UI画像バンドル

プレイマット、カード裏面、NoImage、ハート/ブレードなどのUI用画像は、カード画像とは分けて `loveca-ui-assets.zip` として配布できます。日付付きの `loveca-ui-assets-20260721.zip` のような名前でも読み込めます。

配置方法:

1. 本体zipを展開します。
2. 展開後の `loveca` フォルダ直下へ `loveca-ui-assets.zip` または日付付きのUI画像バンドルを置きます。
3. アプリを起動します。

起動時にバンドルが見つかった場合、必要な場所へ自動配置します。バンドルを展開して `loveca-ui-assets` フォルダとして置いた場合も同様に読み込みます。

## 終了方法

画面右上の `アプリ終了` を押してください。

起動中のシミュレータや更新処理も合わせて終了します。

## 注意

このツールは非公式のローカル補助ツールです。カードテキスト、ルール処理、画像取得結果は、必要に応じて公式情報と照合してください。
